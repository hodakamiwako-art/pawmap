# 韓国犬同伴マップ / Korea Dog-Friendly Map

韓国で**犬と一緒に店内に入れる**カフェ・レストラン2,597軒を、日本語・英語・ハングルで地図から探せるウェブアプリです。ソウルの動物病院とペットショップも収録しています。

👉 **https://hodakamiwako-art.github.io/pawmap/**

ハングルが読めなくても使えるように作っています。店名は日本語の読み仮名（または英語表記）で出し、店員に見せるためのハングル店名と住所は別に大きく表示します。

## できること

- **地図と一覧**から2,597軒を探す（道路・建物・店名が見えるレベルまでズーム可能）
- **地域で絞り込み**（16の広域自治体 → 204の市郡区の2段階）
- **ソウルの動物病院1,011軒**（うち24時間対応48軒）と**ペットショップ1,278軒**を重ねて表示
- **犬と泊まれる宿483軒**（全国。ペンション・ホテル・キャンプ場など）
- **地下鉄・鉄道を常時表示**（ソウル11路線・448駅）
- **最寄り駅と直線距離**を各店に表示（全国1,435駅から算出）
- **Instagram**（315軒）・**電話番号**（333軒）へ直接リンク
- **日本語 ⇄ English の切り替え**。ハングルは常に併記
- **自分のピンを追加**（散歩コース、ドッグラン、動物病院など。名前とメモ付き）
- **現在地から近い順**に並べ替え、距離を表示
- **食事系／施設系**で切り替え、その下のチップでカフェ・ごはん・動物病院・ペットショップ・宿を選択
- 料理ジャンル30種、地域、テラス席の有無で絞り込み
- 日本語・英語・ハングルどれでも検索
- お気に入り登録
- **ログイン**すると、お気に入りと自分のピンが端末間で同期（Supabase）
- Googleマップ／NAVERマップ／DiningCode へのリンク
- ホーム画面に追加してアプリとして起動（PWA）。一度開いた範囲はオフラインでも表示

## 犬の同伴について

掲載している2,597軒は**すべて店内に犬と入れます**。韓国・食品医薬品安全処が公開している
[반려동물 동반 가능 업소（ペット同伴可能業所）登録リスト](https://www.foodsafetykorea.go.kr/portal/petKorea.do)
の**全国全件**です。これは改正食品衛生法にもとづき、犬の店内同伴を正式に届け出た店舗の一覧です。

そのうち**123軒はテラス席もあります**。

⚠️ 犬種・体重の制限（10kg以下など）やケージ／カート必須といった**店独自のルールは公開データに含まれていません**。訪問前に電話かSNSでご確認ください。

## データの精度について

- **位置** — 2,053軒は店舗単位で特定済み。残りは住所からの変換で、建物単位117軒・通り単位355軒・地区中心70軒です。店舗単位でないものは、詳細画面にその旨を表示します
- **未掲載の2軒** — 住所から座標を特定できなかったため落としています（CSVにも含まれません）
- **読み仮名・英語表記** — 100軒は手作業で確認済み。残りはハングルからの機械変換です（借用語辞書＋文化観光部2000年式ローマ字、連音と子音同化に対応）。ブランドの正式な綴りと異なる場合があります
- **料理ジャンル** — DiningCode のカテゴリから分類。カテゴリ情報がない67軒は業態（一般飲食店／軽飲食店／製菓店）から推定しています
- **Instagram・電話番号・動物病院／ペットショップ** — カカオマップに登録されている情報です。店側が更新していない場合があります
- **動物病院とペットショップはソウルのみ**です。24時間対応の判定は店名に「24시」が入っているかで見ています
- **犬と泊まれる宿** — 348軒はカカオマップにペット可と明記されているもの、135軒は店名がペット同伴をうたっているものです。詳細画面にどちらか表示します。頭数・犬種・追加料金などの条件は宿ごとに違うので、予約前の確認が必要です
- **外国語対応は分かりません。** どの動物病院が日本語や英語に対応できるかを示す公開データは韓国に存在しません。サイトを持つ427軒を実際に読んで確認しましたが（取得成功405軒）、外国語ページが見つかったのは5軒だけでした。その5軒に絞る「外国語ページのある病院だけ」という絞り込みは用意していますが、残りが対応できないという意味ではありません。あわせて、受付で見せる韓国語のフレーズを詳細画面に載せています
- **最寄り駅** — 直線距離で最も近い地下鉄駅（1.5km以内）。実際の徒歩距離はこれより長くなります

## 構成

```
index.html              画面
app.js                  アプリ本体（Leaflet）
i18n.js                 日本語・英語の文言
store.js                お気に入り・自分のピンの保管と同期
config.js               Supabase の接続先（空でも動きます）
styles.css              スタイル（ライト／ダーク対応）
sw.js                   Service Worker（オフライン対応）
manifest.webmanifest    PWA 設定
data/places.json        掲載2,595軒
data/subway.json        ソウルの地下鉄の路線と駅
data/pets.json          ソウルの動物病院・ペットショップ
data/stays.json         犬と泊まれる宿
data/seoul-official-486.json  公式登録リストの原本
downloads/              CSV（Googleマイマップに読み込めます）
vendor/                 Leaflet 1.9.4 / supabase-js 2
build/                  データを組み立てるスクリプト
```

ビルド不要の静的サイトです。ローカルで見るには:

```bash
python3 -m http.server 4173
```

## ログインを有効にする

1. [supabase.com](https://supabase.com) で無料プロジェクトを作る
2. SQL Editor で `build/schema.sql` を実行する
3. Settings → API の Project URL と anon public key を `config.js` に書く

`anon key` は公開前提の鍵です。行レベルセキュリティにより、各ユーザーは自分の行しか読み書きできません。
`config.js` が空のままでも地図は動き、お気に入りと自分のピンは端末内に保存されます。

## データの出どころ

- 同伴可否 — [식품의약품안전처 반려동물 동반 가능 업소 현황](https://www.foodsafetykorea.go.kr/portal/petKorea.do)
- 座標・料理ジャンル・評価 — [DiningCode](https://www.diningcode.com/)
- Instagram・電話番号・動物病院／ペットショップ — [カカオマップ](https://map.kakao.com/)
- 住所からの座標変換 — [Nominatim](https://nominatim.openstreetmap.org/)（OpenStreetMap）
- 鉄道の路線・駅 — [OpenStreetMap](https://www.openstreetmap.org/copyright)
- 地図タイル — [CARTO](https://carto.com/attributions) / OpenStreetMap contributors
